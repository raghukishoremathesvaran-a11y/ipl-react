
# IPL 2026 Ticket Booking Website

## Introduction
A responsive IPL ticket booking website developed using React JS, Vite, HTML, and CSS.

## Objectives
- Create a React project using Vite.
- Understand JSX and reusable components.
- Pass match details using Props.
- Render match cards using map().
- Implement State using useState.
- Handle booking form events.

## Features
- Navigation bar
- Hero section
- Upcoming match cards
- Ticket booking popup
- Enter customer name
- Select number of tickets
- Booking confirmation
- Responsive design

## Technologies Used
- React JS
- JavaScript
- JSX
- HTML
- CSS
- Vite

## Components
- Navbar
- Hero
- MatchCard
- BookingForm

## How to Run
1. Install Node.js.
2. Open the project folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL in your browser.

## Learning Outcomes
Learned React components, JSX, Props, State, event handling, and rendering lists using map().
